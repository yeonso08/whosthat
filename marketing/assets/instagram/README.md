## 만드는 법

post-02·03 은 이미지 생성이 아니라 `cards.html` 을 헤드리스 크롬으로 찍은 것이다 — 한글이 깨지거나 문구가 바뀌지 않고, 숫자가 바뀌면 HTML 만 고쳐 다시 찍으면 된다. 서체는 사이트와 같은 Gothic A1·Manrope(구글 폰트, 네트워크 필요).

```bash
cd marketing/assets/instagram
C="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$C" --headless=new --hide-scrollbars --force-device-scale-factor=1 --window-size=1080,1080 \
  --virtual-time-budget=8000 --screenshot="$PWD/post-02/01.png" "file://$PWD/cards.html?c=post02-1"
# c=post02-2 → post-02/02.png, c=post03-1 → post-03/01.png, c=post03-2 → post-03/02.png
```
