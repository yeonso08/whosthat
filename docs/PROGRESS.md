## 진행 중 — 기다리는 것

1. **구글 노출 회복 확인** — 10월 말~11월 초에 Search Console 실적으로 본다(로그인 브라우저 검색으로 보지 말 것). 2026-10-14 에 폰트 preload·sitemap `lastmod` 를 고치고 색인 요청 11건을 넣었다.
   - 솔로지옥 18개 화면(6 × 3언어)이 전부 "발견됨 - 색인 안 됨" 이다. 같은 때 이게 "크롤링됨" 으로 넘어갔는지 함께 본다.
   - 같은 시기 trend-now(keywi.kr)도 떨어졌다. 그쪽 회복 여부와 함께 보면 원인을 가르는 데 도움이 된다.
2. **네이버 수집 확인** — 2026-10-15 에 노출이 없던 기수 30개(나는 솔로 1·4·5·6·7·9·11~15·17·18·20~23·26~33기, 솔로지옥 시즌 1~5, 전부 `/ko/`)를 웹 페이지 수집 요청했다. 10월 말쯤 서치어드바이저의 콘텐츠 노출/클릭 리포트에서 이 기수들이 잡히는지 본다. 33기가 잡히면 `33기 영수 인스타` 같은 인물 검색도 따라와야 한다(2기·8기가 이미 그렇다).
   - **34기도 2026-10-22 에 요청했다** — 계정은 0개지만 직업·나이가 채워졌고 방송 직후 34기를 찾는 사람이 몰려서다. `나는솔로 34기` 류 검색어에 잡히는지 같이 본다.
   - 노출 많고 클릭 적은 검색어(`나는솔로 25기` 1,511회 0.5%, `나는솔로 16기 출연진` 845회 0.5%)가 그대로인지도 같이 본다.
   - **기수 상세의 검색 설명을 바꿨다**(2026-10-19) — 사이트 소개 대신 `출연진 12명, 인스타 6명 확인 — 광수(39·이비인후과 의사), …` 다(`formatMetaCast`). 직업이 있는 한국어 기수(20~32기·솔로지옥)만 해당한다. 배포 2~3주 뒤 위 두 검색어의 클릭률을 0.5% 와 비교한다. 16기는 직업이 비어 있어 이번 변경이 안 걸린다 — 비교 대조군이 된다.
   - **25기는 네이버 블로그 글도 올렸다**(2026-10-20, [HISTORY §9](HISTORY.md)) — 클릭률이 오르면 검색 설명 효과와 블로그 효과가 섞여 있다는 걸 감안한다.
3. **애드센스 3차 심사** — 2026-10-19 에 검토 요청을 넣었다. 구글 노출이 0 인 채로 넣었다 — 기다리기만 해서는 바뀌는 게 없다고 사용자가 판단했다. 거절되면 **사유가 바뀌었는지**부터 본다. 콘솔의 Ads.txt 상태는 "찾을 수 없음" 으로 떠 있지만 9/21 검사값이고, apex → www 308 뒤 200 으로 정상 응답한다.
   - **카카오 애드핏 제휴 제안**도 같은 날 넣었다. 애드핏은 이제 사전 승인·초대제라 제안서(with.kakao.com)가 먼저고, 카카오는 결과를 따로 회신하지 않는다 — 승인되면 인증코드 메일이 온다. 승인되면 할 일: 광고 단위를 코드로 직접 배치(자동 광고가 없다 — `CLAUDE.md` "광고 자리를 코드로 만들지 않는다" 를 함께 고친다), `/privacy` 의 `processor`·`ads` 문단에 카카오 추가 + `effectiveDate`.

4. **25기 AI 브리핑이 돌아오는지** — 25기 결혼 발표(10-22) 뒤 "나는솔로 25기" 검색 상단이 ① 누꼬 인용 → ② 결혼 기사·글 인용 → ③ 브리핑이 사라지고 뉴스 묶음으로 바뀌었다(`marketing/누꼬_홍보_진행일지.md`). 며칠간 하루 한 번 **로그아웃·시크릿 창**으로 검색해, 뉴스가 식은 뒤 브리핑이 돌아오는지와 무엇을 인용하는지(누꼬 25기 페이지 / 결혼 블로그 글 / 다른 곳) 캡처해 진행일지에 적는다. 10-23 에 25기 소개 문단에 결혼 문장을 넣었으니, 돌아온 브리핑이 누꼬를 고르는지가 그 효과다.
